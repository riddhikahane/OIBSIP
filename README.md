# Unemployment Analysis with Python

## Project Overview

This project explores unemployment trends in India using Python and data analysis techniques. The analysis focuses on changes in unemployment rates over time, differences between regions, and unemployment trends during the early COVID-19 pandemic.

Two datasets are analyzed independently to examine unemployment patterns from different perspectives.

## Objectives

- Clean and prepare unemployment datasets for analysis.
- Explore unemployment trends across months and regions.
- Identify regions with relatively high and low average unemployment rates.
- Examine changes in unemployment during the early COVID-19 period.
- Visualize trends and regional differences using Python.
- Perform data quality checks to ensure reliable analysis.

## Technologies Used

- **Python**
- **Jupyter Notebook**
- **Pandas** — data cleaning and manipulation
- **NumPy** — numerical operations
- **Matplotlib** — data visualization
- **Seaborn** — statistical visualizations

## Datasets

### 1. Unemployment in India.csv

The primary dataset contains unemployment estimates for 28 regions, covering May 2019 to June 2020. It includes unemployment rates, estimated employment, labour participation rates, and urban or rural area classifications.

### 2. unemployment rate upto 11 2020.csv

The supplementary dataset contains 267 observations across 27 regions, covering January to October 2020. It also includes geographical coordinates, allowing regional unemployment estimates to be visualized spatially.

**Note:** The datasets were analyzed separately because their estimates and levels of aggregation differ. They were not directly merged.
